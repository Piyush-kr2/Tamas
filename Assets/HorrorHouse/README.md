# Horror House Module

This directory contains all assets, scenes, scripts, and resources for the 3D Horror House environment. This clean structure ensures that the entire house project can easily be exported and merged into the main horror game later.

## Folder Organization

* **`Scenes/`**: Contains Unity scene files (`.unity`) for the house level and test environments.
* **`Prefabs/`**: Contains reusable Unity prefabs (e.g., modular wall units, furniture, doors, lights, player controller).
* **`Models/`**: Contains raw 3D mesh files (`.fbx`, `.obj`, `.blend`).
* **`Materials/`**: Stores URP materials applied to 3D meshes.
* **`Textures/`**: Stores source texture images (e.g., Albedo, Normal maps, Roughness/Metallic maps).
* **`Audio/`**: Stores ambient soundscapes, horror sound effects (SFX), and voice lines (`.wav`, `.mp3`).
* **`Scripts/`**: Stores C# source scripts for game logic, player interactions, door mechanics, and light controls.
* **`Editor/`**: Stores editor-only custom scripts, helper tools, and inspector extensions.
